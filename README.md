# Simple Interest Calculator

## 📌 Description
This project contains a Bash script to calculate Simple Interest based on user input.

## 🎯 Purpose
The purpose of this project is to demonstrate basic Git and GitHub workflow while creating a simple calculator using Bash scripting.

## 🧮 Formula Used
Simple Interest = Principal × Rate × Time

## ▶️ How to Run

1. Clone the repository
2. Navigate to the project directory
3. Run:

   bash simple_interest.sh

4. Enter:
   - Principal amount
   - Rate of interest (decimal format)
   - Time period (years)

## 💡 Example

Enter the principal amount:
1000  
Enter the annual interest rate:
0.05  
Enter the time period:
2  

Output:
Simple Interest: 100
